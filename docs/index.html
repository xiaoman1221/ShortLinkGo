ShortLinkGo 接口文档

基于 Go + Gin + GORM + SQLite 的短链接服务。前端管理后台：统计（含访问地图）/ 链接管理 / 个人中心 / 系统管理。

  • OpenAPI 规范（openapi.yaml）
  • Swagger UI 在线调试

账号与鉴权

系统不再内置默认账号。首个注册用户自动成为超级管理员（UID=1）。角色分为：超级管理员（super）/ 管理员（admin）/ VIP / 用户（user）；被封禁账号无法登录。

1. 登录获取 JWT

curl -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"123456"}'
# 响应 data.token 为 JWT，请求时携带：Authorization: Bearer <jwt>

2. API 令牌（个人中心创建）

令牌用于脚本 / 第三方程序以当前用户身份调用本人短链接接口（增删改查），与 JWT 等效。在「个人中心 → API 令牌」创建，创建时仅展示一次，请妥善保存。

# 列出我的短链接
curl http://localhost:8080/api/links -H "Authorization: Bearer slg_xxxx"

# 创建短链接（自定义短码可选）
curl -X POST http://localhost:8080/api/links \
  -H "Authorization: Bearer slg_xxxx" -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/very/long","code":"summer-sale","remark":"活动"}'

# 更新 / 删除
curl -X PUT  http://localhost:8080/api/links/1 -H "Authorization: Bearer slg_xxxx" -H "Content-Type: application/json" -d '{"status":0}'
curl -X DELETE http://localhost:8080/api/links/1 -H "Authorization: Bearer slg_xxxx"

普通用户创建的短链接默认为「待审核」，审核通过（status=1）后才可访问；管理员/超级管理员创建的链接直接生效。

链接与审核

方法路径说明
GET/{code}访问短链接（302），记录 IP/地理位置/UA
GET / POST/api/links列表（普通用户仅本人；管理员含所有人并带 owner_name）/ 创建
GET / PUT / DELETE/api/links/:id详情 / 更新 / 删除
POST/api/links/:id/review管理员审核：{"status":1} 通过、0 停用、2 待审核

统计

路径说明
/api/stats/summary链接总数 / 累计访问 / 启用 / 待审核 / 过期
/api/stats/trend?days=14按天访问趋势
/api/stats/top?limit=5访问最多 Top 链接
/api/stats/geo?days=30按国家聚合的访问地理分布（访问地图数据源）

IP 地理解析需要服务器放置 MaxMind GeoLite2-City.mmdb（环境变量 GEO_DB_PATH 指向），未配置时公网 IP 归入「未知」，内网归入「内网」。

系统管理（管理员 / 超级管理员）

路径说明
GET /api/admin/users用户列表（管理员及以上）
PUT /api/admin/users/:id/role设置角色（仅超级管理员）
PUT /api/admin/users/:id/status封禁 / 解封（仅超级管理员）
GET / PUT /api/settings读取 / 保存系统设置（站点信息 + SMTP）
POST /api/settings/logo上传站点 Logo（multipart）
POST /api/settings/smtp/test发送 SMTP 测试邮件
GET /api/site站点公开信息（名称 / Logo / 简介），无需登录

其他接口

路径说明
/api/auth/register注册（首个用户为超级管理员）
GET /api/auth/qqQQ 互联登录跳转（系统管理配置 App ID / App Key 后启用）
/api/auth/forgot / /api/auth/reset邮箱找回密码（SMTP 发送重置链接，30 分钟有效）
PUT /api/auth/profile / /api/auth/password / /api/auth/avatar个人资料 / 修改密码 / 上传头像
GET / POST / DELETE /api/tokensAPI 令牌管理
/api/health健康检查

响应统一为 {"code":0,"msg":"succ","data":...}；code 非 0 时与 HTTP 状态码一致。
